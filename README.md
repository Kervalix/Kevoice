# Kevoice
Лёгкое TTS приложение для людей которые не могут говорить, но хотят общаться через Discord.

Особенности:
Оверлей
Вывод на виртуальный кабель (То есть возможность выводить звук в любое приложение)
Бинды для того чтоб быстро воспроизводить сообщения

Настройка:

Скачайте **VB-Cable** с офицального сайта и перезапустите компьютер
Выберите в настройках мессенджерах в качестве микрофона Cable Output
Пишите любой текст в Kevoice и он будет отправляться в мессенджер!

Запуск:

Скачать .exe файл и создать под него отдельную папку
Запустить Kevoice и дождаться конца установки Piper (Он скачивается один раз)
Выбрать один из голосов, прожать "загрузить" и дождаться конца загрузки голоса

Как скачать свой голос:

Для этого, нужно найти .onnx файл для Piper, создать папку в папке "models" (она создаётся после загрузки движка) и закинуть в созданную папку .onnx и .onnx.json файл, после перезапуска Kevoice у вас появятся новый голос.
